## 2. Non-Destructive Blast-Radius Contract (Anti-Regression Lock)

  - `lib/initial-data.ts`:
    - Define `initialPayroll`: Pre-seed official November 2026 payroll records for all 25 real staff members with Nigerian salary structures (NGN ₦) pegged to grade levels (`L0` to `L7`), pre-set to `DISBURSED` status for immediate self-service viewing.

## 3. Schemas & TypeScript Contracts

```typescript
export type PayrollStatus = 'DRAFT' | 'AUDITED' | 'APPROVED' | 'DISBURSED';

export interface PayrollRecord {
  id: string;
  employeeId: string;
  month: string; // e.g. "2026-11"
  organizationArm: OrganizationArm;
  currency: 'NGN';
  basicSalary: number;      // 45% of Gross
  housingAllowance: number; // 25% of Gross
  transportAllowance: number; // 15% of Gross
  utilityAllowance: number;   // 15% of Gross
  grossPay: number;
  taxPAYE: number;          // Statutory PAYE deduction (pegged by Grade Level L0-L7)
  pension: number;          // Statutory 8% employee contribution
  otherDeductions: number;
  netPay: number;           // float-safe: roundNaira(grossPay - taxPAYE - pension - otherDeductions)
  status: PayrollStatus;
  generatedBy: string;      // Victory Kinosi (emp-4)
  auditedBy?: string;       // Yaradua Phibi (emp-2)
  approvedBy?: string;      // Folahan Johnson (emp-1)
  disbursedBy?: string;     // Victory Kinosi (emp-4)
  disbursedAt?: string;     // ISO Timestamp
  auditHash?: string;       // SHA-256 seal for tamper protection
  notes?: string;
}

export interface PayrollSummary {
  month: string;
  totalGross: number;
  totalNet: number;
  totalPAYE: number;
  totalPension: number;
  totalStaff: number;
  status: PayrollStatus;
  breakdownByArm: Record<OrganizationArm, {
    staffCount: number;
    totalGross: number;
    totalNet: number;
  }>;
}

export const roundNaira = (val: number): number => Math.round((val + Number.EPSILON) * 100) / 100;
```

## 4. Numbered Acceptance Criteria

- **AC-1**: When Victory Kinosi (`emp-4`, `role: 'FINANCE'`) logs in, she has direct access to the **Group Payroll & Payslips** module via the sidebar navigation. The module displays monthly total payroll rollups and entity breakdown cards for Switch Advisory, CISD, GX Media House, and Central Services.
- **AC-2**: The Payroll module provides an interactive entity filter allowing Victory, HR, or ED to inspect payroll runs for *All Entities*, *Switch Advisory*, *CISD*, *GX Media*, or *Central Services*.
- **AC-3**: In `GET /api/data`, `payroll_records` is strictly partitioned: Non-finance and non-executive users (`EMPLOYEE`, `LINE_MANAGER`) only receive their own personal payslip records (`employeeId === currentUserId`). Full group-wide payroll records are only served when the caller is authorized (`FINANCE`, `HR_ADMIN`, `SUPER_ADMIN`, or `EXECUTIVE`).
- **AC-4**: In `PersonalProfileModule.tsx`, every logged-in employee (e.g. FJ, Phibi, Tosin, George, Chinonso, Marcus, and staff members) sees a dedicated "My Payslips" tab displaying their historical salary statements.
- **AC-5**: Clicking "View Payslip" opens a clean, printable official digital payslip with company header (Switch Advisory / CISD / GX Media House), itemized allowances, statutory deductions (PAYE, Pension), and net pay in Nigerian Naira (₦).
- **AC-6**: In `app/api/data/route.ts`, unauthenticated dispatch requests or payloads with omitted/invalid identities fail closed with HTTP 401 Unauthorized; the insecure fallback to `SUPER_ADMIN` is eradicated.
- **AC-7**: Four-Eyes Payroll Governance is strictly enforced:
  - Victory (`emp-4`, Finance) executes `GENERATE_PAYROLL` &rarr; status becomes `DRAFT`.
  - Phibi (`emp-2`, HR Lead) audits and dispatches `AUDIT_PAYROLL` &rarr; status becomes `AUDITED`.
  - Folahan Johnson (`emp-1`, Executive Director) dispatches `APPROVE_PAYROLL` &rarr; status becomes `APPROVED`.
  - Victory dispatches `DISBURSE_PAYROLL` &rarr; status becomes `DISBURSED`, stamping `disbursedAt` and sealing the run. Self-approvals are blocked.
- **AC-8**: In `TasksModule.tsx`, when Line Managers (George for GX, Chinonso for Switch, Marcus for CISD) create a task, the assignee dropdown is filtered strictly to personnel within their sister arm. Server-side validation in `route.ts` rejects cross-arm task forgery with HTTP 403.
- **AC-9**: Cross-Arm Collaboration: Switch Advisory and CISD Line Managers can commission creative deliverables from GX Media House by flagging the task as a Cross-Arm Request (`collaborationArm: 'GX_MEDIA'`), routing it to GX Lead (George) or HR Lead (Phibi) for assignment.
- **AC-10**: In `AnnouncementsModule.tsx`, creators can designate `targetArm`: *All Entities (Group-wide)*, *Switch Advisory*, *CISD*, or *GX Media*. Notices display the target entity's semantic badge, and Line Managers can only broadcast announcements scoped to their own arm.
- **AC-11**: In `PerformanceModule.tsx`, Line Managers only see appraisal reviews for direct staff belonging to their entity. In `AssetManagementModule.tsx`, Line Managers view equipment assigned to their entity's personnel, while regular staff view only their personally assigned items in `PersonalProfileModule`.
- **AC-12**: In `lib/sqlite.ts`, `saveDatabaseSnapshotToSqlite()` deletes child `payroll_records` *before* `employees`, preventing SQLite Foreign Key constraint failures. Pre-seeded November 2026 payroll records guarantee immediate persistence upon Vercel serverless cold-start hydration.
- **AC-13**: All currency calculations are float-safe via `roundNaira()`. Disbursed payroll records are immutable; mutation attempts on disbursed records return HTTP 409 Conflict.
- **AC-14**: The Digital Payslip modal renders responsively on 375px mobile screens (`grid-cols-1 sm:grid-cols-2`), entity filter pills scroll horizontally without wrapping, and `@media print` isolates the printable payslip document. Legacy persona references are completely eradicated.
